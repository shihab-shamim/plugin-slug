== Description ==

[Plugin Demo](https://bblockswp.com/demo/live-chats) | [Documentation](https://bplugins.com/docs/live-chats) | [Get Pro Version](https://bblockswp.com/demo/live-chats/#pricing)

**[Demos](https://bblockswp.com/demo/live-chats)**

Live Chats is a lightweight and customizable WordPress block plugin that lets you add interactive live chat widgets to your site so visitors can connect with you in real time.


### Live Chats Features
- **Easy Live Chat Integration**: Add a live chat block directly from the Gutenberg editor.
- **Customizable Styling**: Adjust alignment, colors, and appearance from the block sidebar.


### Live Chats Pro Features
- **Advanced Customization**: Unlock additional styling and live chat options.


= How to use Live Chats =
- First, install the Live Chats plugin from the WordPress dashboard.
- Add the Live Chats block from the block category called "widgets" in the Gutenberg editor.
- You can change block settings from the right-side settings sidebar.
- Enjoy!

* For installation help click on Installation Tab

== Installation ==

### From Gutenberg Editor:
1. Go to the WordPress Block/Gutenberg Editor
2. Search For **Live Chats**
3. Click on the **Live Chats** to add the block

### Download & Upload:
1. Download the **Live Chats** plugin (*.zip file*)
2. In your admin area, go to the Plugins menu and click on **Add New**
3. Click on **Upload Plugin** and choose the **`live-chats.zip`** file and click on **Install Now**
4. Activate the plugin and Enjoy!

### Manually:
1. Download and upload the **Live Chats** plugin to the **`/wp-content/plugins/`** directory
2. Activate the plugin through the Plugins menu in WordPress
